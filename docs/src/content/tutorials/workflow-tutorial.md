# Multi-Step Workflow Tutorial 🎓

This tutorial walks through building, validating, saving, and running a complete end-to-end user onboarding workflow in Jetic.

---

## 🎯 Scenario Overview

We want to test an E-Commerce API with 3 sequential operations:
1. **Register Workspace & Admin**: Post credentials generated by Faker, capturing `adminEmail` & `adminPassword` pre-flight (`captureInput`) and `workspaceID` post-flight (`capture`).
2. **Admin Login**: Log in with captured credentials, capturing `accessToken` JWT.
3. **Create Store Item**: Post a new product using `Authorization: Bearer {{workflow:accessToken}}` (`inject`).

---

## 📝 Step 1: Authoring Workflow JSON

Create `.jetic/workflows/shop-setup.json`:

```json
{
  "name": "Shop setup and product creation",
  "generatedAt": "2026-09-18T10:00:00.000Z",
  "steps": [
    {
      "name": "Register Admin Workspace",
      "method": "POST",
      "path": "/api/workspaces/setup",
      "description": "Register workspace and capture credentials",
      "body": {
        "company_name": "{{faker.company.name}}",
        "email": "{{faker.internet.email}}",
        "password": "{{faker.internet.password}}"
      },
      "captureInput": {
        "workflow:adminEmail": "email",
        "workflow:adminPassword": "password"
      },
      "capture": {
        "workflow:workspaceID": "data.workspace.id"
      },
      "expectStatus": 201
    },
    {
      "name": "Admin Login",
      "method": "POST",
      "path": "/api/auth/login",
      "description": "Log in with generated admin credentials",
      "body": {
        "email": "{{workflow:adminEmail}}",
        "password": "{{workflow:adminPassword}}"
      },
      "capture": {
        "workflow:accessToken": "data.token"
      },
      "expectStatus": 200
    },
    {
      "name": "Create Product",
      "method": "POST",
      "path": "/api/products",
      "description": "Create product with Bearer authorization token",
      "inject": {
        "header:Authorization": "Bearer {{workflow:accessToken}}"
      },
      "body": {
        "name": "{{faker.commerce.productName}}",
        "price": 99,
        "workspaceId": "{{workflow:workspaceID}}"
      },
      "expectStatus": 201
    }
  ]
}
```

---

## ⚡ Step 2: Simulating the Workflow

Run via CLI:

```bash
jetic simulate workflow --workflow .jetic/workflows/shop-setup.json --verbose
```

Or run via Jetic Studio (`jetic dev`) on the `/simulations` page to view real-time execution steps and node-graph traces under `/traces`!
